# Phishing URL Detection Using Logistic Regression

## 1. Project Overview
This project aims to classify URLs as phishing or legitimate using the Logistic Regression machine learning algorithm.

## 2. Project Objective
The objective is to build a machine learning model that learns from URL-related features and predicts whether a URL may be phishing or legitimate.
